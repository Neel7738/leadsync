01 — The Pipeline

One API call. Full pipeline.

A single POST request processes a conversation end-to-end. Score it, determine the action, generate drafts, queue it, track it.

📥

Ingest

Email, calls, meetings — parsed with LLM entity extraction

🧠

Score

Weighted AI scoring: urgency, deal value, engagement, recency

✍️

Generate

3 tone variants: agreeable, direct, soft — via intelligent LLM fallback

🚀

Deliver

Email with tracking pixels, 7-channel SLA breach alerts

02 — Features

Built for real sales teams.

Every feature solves a real problem. No stubs, no mocks — production-grade implementations.

🔄

Intelligent LLM Fallback

Routes through OpenAI, Anthropic, Google, Groq, NVIDIA NIM, then falls back to local Ollama. Zero downtime.

🔔

7-Channel Alerting

Telegram, Email, Slack, Discord, Teams, PagerDuty, Opsgenie — all simultaneously on SLA breach.

🔐

2FA Security

TOTP authentication, backup codes, recovery links, mandatory enforcement for admins.

⚡

Real-Time Updates

WebSocket queue events, live dashboard, webhook payload inspector for debugging.

📊

CSV/PDF Export

Compliance-ready exports with filtering by date, source, urgency. Full audit trail.

🐳

Docker Ready

Full Docker Compose with PostgreSQL, Redis, Prometheus, Grafana. One command to deploy.
